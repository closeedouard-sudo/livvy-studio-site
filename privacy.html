Privacy policy

Last updated: October 21, 2026

What the app accesses

livvy-studio requests access to Google Drive for a single account: the owner's own account. It reads image and video files that the owner places in dedicated folders, and writes the generated content back into dedicated folders in that same Drive.

How data is used

Files are used only to produce and organize content for the owner. They are processed by the owner's private automation (GitHub Actions) and AI services used for image/video generation and quality review. No data is sold, shared for advertising, or used for any other purpose.

Storage and retention

Files remain in the owner's Google Drive. Temporary copies made during processing are deleted when each automated run ends. Access credentials are stored as encrypted secrets.

Google API Services User Data Policy

livvy-studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
